# Roadmap "Build Roulette"

Статус фич по плану. Обоснования решений — в `decisions.md`, здесь только чек-лист.

1. [x] **Инфраструктура** — репозиторий GitHub, GitHub Pages, каркас `index.html`.
2. [x] **Синхронизация данных** — GitHub Action на cron (раз в 3 мин), тянет CSV участников
   и справочник "Умения и классы" из Google Sheet.
3. [x] **Иконки PoE** — извлечены напрямую из клиента игры (`pathofexile-dat` + ImageMagick,
   разово), лежат в репозитории (`img/skills/`, `img/ascendancies/`).
4. [x] **Таблица участников** — рендер из `data/participants.csv`, названия колонок
   соответствуют Google Sheet.
5. [x] **Попап-рулетка** — слот-барабаны, реролл по частям с лимитами (боссы + счётчик
   рероллов из Sheet), фанфары.
6. [x] **Зона превью "песочные часы"** — чёрная зона с шариками игроков (раздел 5/6/10
   `decisions.md`): покачивание вверху, переезд вниз и более активное движение после
   розыгрыша.
7. [x] **Экспорт результата** — кнопка скачать итоговый CSV (`Логин, Подкласс, Умение,
   Выдан слот, Был реролл`).
8. [ ] **Полировка** — звук, стили, доводка анимаций.
